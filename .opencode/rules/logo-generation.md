# Logo Generation

Use these rules for every generated or revised Libryva logo.

## Brand treatment

- Use the supplied primary Libryva mark as the style reference.
- Use an opaque `#050505` background, `#38CD65` for the bright left page, and `#33AA57` for the deeper right page.
- Keep the mark flat, geometric, and minimal: no gradients, glow, shadows, outlines, 3D effects, text, flags, maps, people, or extra symbols.
- Center one standalone mark with at least 12% clear padding on every edge.

## Polyglot

- Depict a wide, shallow open book lying flat, never an upright book.
- Place one compact three-dot speech bubble directly above the centre fold so the book visibly appears to be talking.

## Delivery

- Inspect the primary reference and any target asset before generation; preserve requested invariants when revising an existing logo.
- Use built-in image generation for raster assets, inspect the result at full and icon scale, and deliver a 512×512 RGBA PNG to the requested project path.
