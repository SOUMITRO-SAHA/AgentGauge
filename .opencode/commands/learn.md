description: Capture durable task learnings in .opencode/contexts/
---

Capture durable learnings from the current task in `.opencode/contexts/`.

1. Inspect the existing files and folder structure under `.opencode/contexts/` before deciding where anything belongs. Consider the current task and its outcome; use `$ARGUMENTS` as additional context when provided.
2. If the context structure genuinely makes the relevant learning hard to find, reorganize only files within `.opencode/contexts/`, preserving their existing useful content. Do not reorganize merely for style or make unrelated cleanup changes.
3. Add or update **only the one context file most relevant to this task**. Create `.opencode/contexts/` and a suitably named file if needed. Keep the learning concise, reusable, factual, and actionable; distinguish verified project facts from assumptions. Do not copy secrets, personal data, or a transcript of the task.
4. Do not modify files outside `.opencode/contexts/`.
5. If the task produced no durable learning, leave the context files unchanged and say why.

Report the context file updated (and any necessary context-only reorganization), or that no update was needed.
